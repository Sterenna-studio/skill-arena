# Ardamir — Panneau de réactions

Petite page web statique interactive autour des réactions du personnage. La source est conservée dans ce dossier; `public/games/ardamir` contient la version statique servie par Skill Arena.

## Jouer

Ouvre `index.html` localement ou passe par la hero card Ardamir du hub. Le défi consiste à retrouver le portrait demandé parmi dix expressions en 30 secondes; les dialogues associés restent modifiables dans `script.js`, dans le tableau `emotes`.

Les PNG d'origine sont conservés ici en une seule copie par empreinte SHA-256. Les variantes walk et les neuf portraits expressifs alternatifs sont gardés pour une réutilisation future. Les portraits PNG de 1254×1254 sont convertis en WebP 840×840 dans la version publique pour réduire le poids.
