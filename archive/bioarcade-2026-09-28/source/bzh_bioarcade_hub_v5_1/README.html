Direction artistique (v1)

Un hub “cockpit” qui regroupe des modules de jeu. Même logique que BZH Chronicles : techno usée + organique + symboles, sans surcharger l’UI.

Principes UI

  • Cartes arrondies, verre sombre, bordures fines.
  • Accents “bio-neon” (vert/teal) + “void/violet” pour la mystique data.
  • Cuivre en troisième accent (artefact / héritage).
  • Typo system (rapide). On pourra plug Cinzel/etc. si tu veux une vibe plus “gazette” sur certains modules.

Palette

Les couleurs sont définies en CSS variables dans shared/base.css. Comme tu as une palette stricte côté assets/pixel-art, tu peux remapper ici en 2 minutes : 
:root{
  --bg0: ...; --bg1: ...; --bg2: ...;
  --fg0: ...; --fg1: ...; --muted: ...;
  --accent: ...; --accent2: ...; --copper: ...;
}
