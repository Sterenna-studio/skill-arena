# Prompt Codex — Spirit Overdrive

Ce repo contient un mini-jeu web vanilla HTML/CSS/JS.

Direction actuelle : **simple jeu de course automobile simulée**.

Ne pas réintroduire de systèmes lourds sans demande explicite :

- pas de Heat
- pas de loot
- pas de dégâts/réparations
- pas d'inventaire complexe
- pas d'adversaires détaillés

Le cœur du jeu :

```text
voiture → amélioration → course → simulation → gains
```

Priorités :

1. Garder l'UI lisible et peu chargée.
2. Garder peu de stats.
3. Faire des courses rapides à simuler.
4. Équilibrer crédits, réputation et difficulté.
